API da aplicação

Endpoints no mesmo domínio do painel. As credenciais esportivas permanecem no servidor.

GET /api/dashboard

Retorna partidas, análises, odds comparáveis, fontes, horários de coleta, avisos e estado da integração. Sem credencial, retorna uma lista vazia com configured=false. Probabilidades ausentes são null.

A resposta é um snapshot persistido; consultá-la não gera chamadas à API esportiva. Odds antigas ou jogos iniciados têm eligible=false.

GET /health

Verifica o processo e informa se uma chave foi preenchida. Não valida o plano, a chave ou a cobertura dos jogos.

POST /api/refresh

Exige Authorization: Bearer <ADMIN_TOKEN>. Sem token configurado no servidor, a coleta manual está desativada (403). Token ausente ou incorreto retorna 401. Uma coleta em execução retorna already_running.

A atualização automática não depende desse endpoint e ocorre em um único worker. Não compartilhe o token com o navegador.

Especificação OpenAPI

Abrir /openapi.json para usar com um cliente de API.
